# Evolutionary Optimization

A collection of evolutionary optimization algorithms implemented in PyTorch and NumPy for learning and research.

## About

The initial implementation of this project was written during my second undergraduate semester. This repository contains an improved and continuously evolving version of that implementation, with an emphasis on clean code, modular design, and research-oriented development.

## Scope

This repository focuses on implementing foundational evolutionary optimization algorithms from scratch. For algorithm variants and extensions that already have mature open-source implementations, the emphasis is on understanding, evaluation, and research rather than reimplementing existing software.

- [x] NSGA-III (Initial implementation)
